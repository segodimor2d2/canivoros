# Growth Partners

## Nuestro principal objetivo es mapear los PROBLEMAS que las empresas tienen en el MERCADO

si conseguimos mapear los problemas del mercado de nuestros clientes, podemos diseñar y automatizar estrategias para...
- ayudar con el crecimiento de las empresas
    - aumentar los ingresos
    - aumentar la velocidad de los procesos
    - resolver problemas con mas agilidad
    - tener visibilidad del comportamiento interno/externo
    - aumentar los clientes
    - crear leads
    - convertir leads
    - clientes recurrentes
    - automatizar ventas

Como? *Necesitamos entender el mercado de los clientes...*
- Como:
    - Colectando datos INTERNOS
        - datos financieros ORP
        - bases de datos flujo interno de procesos ORP
        - diseñando/implementando herramientas para colectar datos
    - Colectando datos EXTERNOS
        - usar fuentes de datos confiables
        - investigación de mercado
            - estrategias para colectar datos
            - diseñando herramientas para colectar datos

    - Analizando datos para tener INSIGHTS (*esto es lo principal*) 

    - Diseñar y automatizar estrategias que resuelvan los problemas (*futuro*)


## qué debemos definir pronto?

### BENCHMARKING COMPETITIVO/FUNCIONAL
Comparar el desempeño de competidores directos con criterios comunes
Aprender de empresas que destacan en una función, aunque sean de otro sector

Criterios:
- precio
- público (empresas pequeñas. medias, grandes)
- productos/servicios
    - funcionalidades
